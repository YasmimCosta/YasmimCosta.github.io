# 🐦‍⬛🌸 Taverna do Corvo Rosa

Uma taverna virtual para suas sessões de RPG de mesa. Converse com seu grupo, role dados, toque música ambiente e gerencie seu personagem — tudo em um só lugar.

## ✨ Funcionalidades

- 💬 **Chat em tempo real** — converse com seu grupo durante a sessão, com suporte a mensagens do mestre e dos jogadores
- 🎲 **Rolagem de dados** — role d4, d6, d8, d10, d12, d20, dados customizados e combinações (ex: `2d6+3`)
- 🎵 **Música ambiente** — trilha sonora temática para dar clima às cenas (taverna, combate, exploração, tensão)
- 🔊 **Sons ambientes** — efeitos sonoros para imersão (fogueira, chuva, multidão, espadas, etc.)
- 👤 **Perfil de jogador** — crie e personalize seu personagem, avatar e ficha

## 🛠️ Tecnologias

> _CSS, JavaScript, HTML e Firebase como base de dados_
